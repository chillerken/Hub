# FitLog PPL

Eenvoudige offline Android fitnesslog voor de PPL-herstart.

- PUSH / PULL / LEGS
- startdoelen ingebouwd
- laatste PULL-training vooraf ingevuld
- log gewicht, reps en RIR
- alles lokaal via SharedPreferences
- kopieer een training in één tik om in ChatGPT te plakken

## Build

```bash
gradle assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`
